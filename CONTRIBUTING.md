# Как участвовать в разработке Glint

Glint — неофициальный клиент Яндекс Музыки. Перед изменениями прочитайте `README.md` и
`NOTICE.md`: проект работает с неофициальным API, а часть данных приходит от внешних сервисов.

## Локальная разработка

Нужны `rustup` и Rust из `rust-toolchain.toml`.

```bash
cargo test --workspace
cargo run --release -- --list-scenes
```

Для UI-сцен используйте headless-инструменты из feature `tooling`:

```bash
cargo run --release -- --snap out.png --scene nowplaying --size 1320x820
```

Перед pull request прогоните `cargo test --release --locked --workspace`. Не добавляйте токены,
настройки пользователя, собранные бинарники или файлы из `dist/`.

## Изменения и pull request

- Один pull request должен решать одну связанную задачу.
- Новое поведение сопровождайте тестом, который проверяет пользовательский результат или важный
  протокол, а не конкретную форму реализации.
- Для изменений UI приложите скриншот headless-сцены, если это помогает проверить результат.
- Обновите README, NOTICE или release notes, если меняются внешние сервисы, лицензии или поведение
  релизной сборки.
- Не меняйте версию и тег релиза в обычном pull request.

Не отправляйте реальные OAuth-токены в issues, pull requests и логи CI.
